# Sajilo Sweets House Demo

Responsive orange-and-white website for a Nepali sweets house.

### Features
- NPR / Rs. prices only
- Per-piece and approximate weight ordering
- Cart and quantity controls
- Demo online checkout form
- Dashain offer and Rs. 1,499 festive box
- Customer reviews
- Menu category filtering
- About and contact sections
- Responsive mobile/laptop layout

Open `index.html` in a browser. Replace the placeholder phone, email and address with the real store details.

This is a frontend demo; the checkout is not connected to a real payment gateway or database.


Updated: Dashain and Tihar are now a dedicated Offers section, separate from Reviews, with improved contrast and festive visuals.
