# Sajilo HUB — Clothing Store Sample

A responsive, front-end clothing store demo built for a web-agency portfolio.

## Included features
- Responsive desktop/tablet/mobile layout
- Home page with scrollable product collection
- Product photos, names, prices, old prices and sale badges
- Product ratings
- Product color swatches
- Search bar
- Filters:
  - Price low to high
  - Price high to low
  - Rating
  - 5/4/3/2/1 star thresholds
  - Category
  - Sale
  - Regular
- Load more products
- Product checkout drawer/modal
- Customer name and contact
- Size selection
- Color selection
- Delivery location
- Cash on Delivery
- Online Payment placeholder
- Order summary and delivery charge
- Location tab opens a dedicated location section instead of showing the location panel permanently
- Store address, hours and contact details
- Demo map with route visualization
- Mobile navigation

## Run
Open `index.html` in a browser.

The product photos use public Unsplash image URLs, so an internet connection is recommended for the images.

## Production notes
This is a portfolio/demo front end. All sample prices are displayed in Nepali Rupees (Rs.). The online payment option is intentionally a placeholder. For a real store, connect a backend/database and a payment provider such as eSewa, Khalti, Stripe, etc., and validate/store orders securely on the server.
